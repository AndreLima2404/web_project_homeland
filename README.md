# De Pátria para Pátria

## Descrição do projeto

Página de destino (landing page) para uma exposição da galeria de arte
TripleTen chamada "De Pátria para Pátria". A página apresenta a exposição e
convida os visitantes a conhecerem um pouco mais sobre a localização de
seus colegas de turma. O layout é totalmente responsivo, adaptando-se a
telas de desktop, tablet e celular.

## Tecnologias e técnicas utilizadas

- HTML5 semântico
- CSS3 (Flexbox, media queries)
- Metodologia BEM com estrutura de arquivos BEM Flat
- Design responsivo (mobile-first) para os breakpoints 320px, 768px e
  1280px
- Fonte Inter hospedada localmente
- normalize.css para padronizar estilos entre navegadores
